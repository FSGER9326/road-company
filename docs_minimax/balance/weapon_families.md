# Weapon Families - ROAD COMPANY

## Core Weapon Stats (Base Values)

| Stat | Description |
|------|-------------|
| AP Cost | Actions points to attack |
| Fatigue | Fatigue cost per attack |
| Damage | Base damage range (roll 1dX-Y) |
| Armor Damage | % of damage that bypasses armor |
| Hit Mod | Accuracy modifier |
| Special | Unique actions available |

---

## 1. Longblade (Sword Equivalent)

**Tactical Identity:** Balanced reach and damage. Excels in duels and formation fighting.

| Stat | Value |
|------|-------|
| AP Cost | 2 |
| Fatigue | 4 |
| Damage | 12-22 |
| Armor Damage | 20% |
| Hit Mod | +0 |

**Special Actions:**
- **Lunge** (AP 3, FAT 6): +2 reach, +15 accuracy, +50% armor ignore
- **Parry** (AP 1, FAT 2): Block next attack, counterattack opportunity
- **Blade Storm** (AP 4, FAT 8): Hit all adjacent enemies once

**Best User:** Veterans, duelists, formation fighters
**Counters:** Shield users, heavy armor if not using Lunge
**Progression:** Rusty blade → Iron longblade → Steel longblade → Masterwork blade → Runeforged longblade

## 12. Alchemical Weapons (Utility Weapons)

**Tactical Identity:** Area denial, terrain control, debuffs. Limited uses per rest.

| Stat | Value |
|------|-------|
| Uses | 2-4 per rest |
| Range | 4-8 hexes |
| Radius | 1-3 hexes |

**Types:**

### Firebomb
- Damage: 12-18 (50% armor ignore)
- Effect: Burning condition (3 damage/turn for 2 turns)
- Radius: 2 hexes

### Smoke Candle
- Damage: 0
- Effect: Creates smoke cloud, -20 accuracy for all in zone, blocks LOS
- Radius: 3 hexes

### Acid Vial
- Damage: 8-12
- Effect: -20 armor for 3 turns
- Radius: 1 hex (single target)

### Alchemical Fire
- Damage: 18-28
- Effect: Burning + lingering (2 damage/turn for 2 turns after initial)
- Radius: 2 hexes

### Frost Powder
- Damage: 6-10
- Effect: Slowed (-1 AP) for 2 turns
- Radius: 2 hexes

**Best User:** Siege specialists, trap setters, terrain controllers
**Counters:** Ranged enemies out of range, enemies with condition resist
**Progression:** Basic alchemical → Reinforced vials → Master alchemical → Runed alchemical → Dragon's breath
